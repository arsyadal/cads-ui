# CadsUI

Premium motion components for React, Tailwind, and shadcn-style projects.

## MVP 0.1

- Floating Island Navbar
- Morph Modal
- Magnifier Dock
- Landing page
- Component docs with usage, props, and accessibility notes

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Philosophy

CadsUI is copy-paste first. Components live in `components/cadsui/*` so developers can own and customize the source.
